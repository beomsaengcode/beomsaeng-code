# 문서를 어떻게 자르면 AI가 덜 틀리나

가상 쇼핑몰 '하늘몰' 상담 규정(`policy.txt`)을 두 가지 방법으로 잘라 같은 질문 10개를 물어봐요.

| 자르는 방법 | 조각 수 | 맞힌 질문 |
|---|---|---|
| 100자씩 자르기 | 29 | 2 / 10 |
| 항목(`# 제목`) 단위로 자르기 | 14 | 7 / 10 |

- 검색: 질문과 글자 두 개 묶음이 가장 많이 겹치는 조각 하나만 AI에게 붙여요. 임베딩 없이, 자르는 위치 문제만 보이게 했어요.
- 답: Ollama `qwen2.5:1.5b` (무료, 내 PC), temperature 0
- 채점: 답에 정답 낱말이 모두 들어 있어야 맞음 (엄하게 셈)

```bash
ollama pull qwen2.5:1.5b
python measure.py   # → measure.json
```

틀린 질문은 `measure.json`의 `chunk`(AI가 실제로 받은 조각)부터 보세요.
